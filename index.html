Kebijakan Privasi Baku Tola

Terakhir diperbarui: 5 November 2026

Kebijakan privasi ini menjelaskan bagaimana game Baku Tola (paket aplikasi com.bakutola.game) menangani informasi pengguna saat dimainkan.

1. Pengumpulan dan Penggunaan Data

Game Baku Tola tidak mengumpulkan, menyimpan, melacak, mentransfer, memperjualbelikan, atau membagikan data pribadi pengguna dalam bentuk apa pun. Kami tidak meminta akses ke kontak, lokasi GPS, kamera, mikrofon, atau data sensitif perangkat Anda.

2. Fitur Multipemain Jaringan Lokal (LAN)

Game ini menyediakan fitur pertempuran multipemain melalui jaringan lokal (LAN) menggunakan pertukaran kode ruangan dalam jaringan Wi-Fi lokal yang sama. Semua paket komunikasi data jaringan diproses secara langsung antar-perangkat (peer-to-peer/lokal) dan tidak pernah dikirimkan ke server eksternal kami.

3. Iklan dan Layanan Pihak Ketiga

Aplikasi ini tidak menyertakan SDK pelacak analitik pihak ketiga maupun jaringan iklan komersial luar.

4. Privasi Anak-Anak

Karena Baku Tola tidak mengumpulkan informasi pengenal pribadi apa pun, aplikasi ini aman untuk pengguna segala usia, termasuk anak-anak di bawah umur.
